# Placement Analysis

Analyze campus placement data and predict whether a student gets placed.

## Models Used
- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors
- Bernoulli Naive Bayes
- Support Vector Machine (SVC)
- **XGBoost**

## Pipeline
- EDA with visualizations (boxplots, countplots, heatmaps)
- Label encoding
- Train/test split
- Multi-model comparison with cross-validation
- ROC-AUC evaluation

## Dataset
- `Placement_Data_Full_Class.csv` — 215 rows, 15 columns
- Features: demographics, academic percentages, work experience, MBA status, specialisation
