# Medical Cost Analysis

Predict individual **medical insurance costs** based on demographic and health attributes.

## Models Used
- Linear Regression
- Polynomial Features + Linear Regression
- Random Forest Regressor

## Pipeline
- EDA and label encoding
- Polynomial feature engineering
- Train/test split
- Model training and evaluation (R², RMSE)

## Dataset
- `insurance.csv` — 1,338 rows
- Features: age, sex, bmi, children, smoker, region, charges (target)
