# Laptop Price Prediction

Predict laptop prices based on technical specifications using regression models.

## Pipeline
- EDA and data visualization
- Outlier removal (Z-score)
- Label encoding and feature scaling
- Decision Tree and Random Forest regression
- Hyperparameter tuning with GridSearchCV
- Residual analysis and feature importance

## Datasets
- `laptops_train.csv` — ~900 rows, 13 features
- `laptops_test.csv` — ~100 rows
- Features: Manufacturer, Screen Size, CPU, RAM, Storage, GPU, OS, Weight, Price
