# Customer Segmentation — Online Retail

Perform **RFM (Recency, Frequency, Monetary)** analysis and customer segmentation on UK online retail transactional data.

## Pipeline
- Data cleaning and preprocessing
- Feature engineering: RFM metrics
- Customer segmentation analysis

## Dataset
- `Online Retail.xlsx` (~541K rows)
- Columns: InvoiceNo, StockCode, Description, Quantity, InvoiceDate, UnitPrice, CustomerID, Country

## Requirements
```
pip install -r requirements.txt
```
