# Income Analysis

Predict whether annual income exceeds **$50K** using UCI Adult census data. Binary classification with Logistic Regression.

## Pipeline
- EDA and data visualization
- Data preprocessing and feature scaling
- Logistic Regression classification
- Evaluation: accuracy, confusion matrix, classification report

## Dataset
- `income_evaluation.csv` — ~32K rows
- Features: age, workclass, education, marital-status, occupation, race, sex, capital-gain, hours-per-week, native-country
