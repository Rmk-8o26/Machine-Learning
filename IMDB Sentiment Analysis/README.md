# IMDB Sentiment Analysis

Classify IMDB movie reviews as **positive** or **negative** using NLP preprocessing and traditional ML classifiers.

## NLP Pipeline
- Tokenization (word, sentence, regex)
- POS tagging
- Stopword removal
- Lemmatization (WordNet)
- TF-IDF vectorization

## Models Used
- Naive Bayes
- Support Vector Machine (SVM)
- Logistic Regression

## Dataset
- **Source:** [IMDB 50K Movie Reviews](https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews) — Kaggle
- 50,000 reviews labeled positive/negative
