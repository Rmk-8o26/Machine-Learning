# Heart Disease Prediction

Predict the presence of **heart disease** in a patient using classification models.

## Models Used
- Gaussian Naive Bayes
- Logistic Regression

## Pipeline
- EDA with seaborn/matplotlib
- Train/test split with feature scaling
- Model training and evaluation
- Metrics: accuracy, confusion matrix, classification report

## Dataset
- `heart.csv` — 303 rows, 14 columns
- Features: age, sex, chest pain type, cholesterol, blood pressure, max heart rate, etc.
