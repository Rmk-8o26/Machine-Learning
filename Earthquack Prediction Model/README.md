# Earthquake Prediction Model

Predict **earthquake magnitude** from historical seismic data using regression models.

## Pipeline
- Data loading and preprocessing
- Geographic visualization with Basemap
- Train/test split
- Linear Regression and Random Forest regression
- Model evaluation

## Dataset
- `database.csv` — ~23K rows, 21 columns
- Features: Date, Time, Latitude, Longitude, Depth, Magnitude, error/station data
