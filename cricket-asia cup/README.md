# Cricket Asia Cup Data Analysis

Exploratory data analysis of **Asia Cup cricket matches** from 1984 to 2022 using interactive Plotly visualizations.

## Contents
- Data loading and basic statistics
- Interactive visualizations with Plotly Express and Plotly Graph Objects
- Team and player performance analysis

## Dataset
- `asiacup.csv` — 255 rows, 20 columns
- Features: Team, Opponent, Format, Ground, Year, Toss, Runs, Wickets, Fours, Sixes, Run Rate, Strike Rate, etc.

## Requirements
```
pip install -r requirements.txt
```
